HackOn Photo & Video DeDupe — Install

Requirements

  • Python 3.10 or newer (the app is developed on 3.15).
  • Windows 10/11 or macOS. A local folder or a network share to scan.
  • FFmpeg / ffprobe (for video resolution, codec and length) is handled for you:

on Windows, open Setup → Options and click GET FFMPEG — the app downloads it into its own folder (no winget, no admin, nothing installed system-wide). On macOS, if ffprobe is on your PATH the app uses it; a one-click download for Mac is coming. Photo and movie/TV duplicate-finding works with or without it — it only adds the video details column.

Install & run (from source)

# 1. Get the code (download the ZIP or clone the repo), then open a terminal in its folder.

# 2. Make a virtual environment
python -m venv .venv

# 3. Activate it
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux

# 4. Install dependencies
pip install -r requirements.txt

# 5. Run it
python app.py

The app opens your default browser at http://127.0.0.1:5000 automatically. Start it with python app.py --no-browser to skip that — useful when you're running it on a headless machine or want to open the page yourself (the web interface is the only UI, so you'll still browse to that address).

By default the app answers only on the machine it runs on (127.0.0.1). To reach it from another computer — for example running it on a server or NAS — give it a network address:

python app.py --no-browser --host 0.0.0.0

Then browse to http://<that-machine's-ip>:5000 from elsewhere on your network. Security: the app has no password and can move or delete files, so only open it to networks you trust; if it's still unreachable after this, allow TCP port 5000 through that machine's firewall. The Windows installer offers an "Allow other computers on your network to reach it" checkbox (off by default) that opens that port for you on Private networks and removes it on uninstall.

First run

  1. The SETUP page opens. You can SKIP FOR NOW — photo scanning needs no setup.
  2. Optional: on first run, press PROBE LOCAL NETWORK to find Radarr/Sonarr/Plex/Jellyfin, or enter them

by hand, then SAVE SETTINGS.

  1. Go to PHOTO SCAN, pick a folder, and RUN SCAN.

Updating

Pull/download the new code, then with the virtual environment active run pip install -r requirements.txt again in case dependencies changed, and start the app.

Where your data lives (kept out of version control)

File / folderWhat it holds
settings.jsonYour settings and folder shortcuts (API keys/token are in the OS keychain, not here)
results.json, movie_results.json, tv_results.jsonThe latest scan results
fingerprints.jsonCached photo fingerprints (so rescans are fast)
moves.json, movie_moves.json, tv_moves.jsonUndo history for moves
deleted_photos.json, deleted_movies.json, deleted_tv.jsonRecords of files you deleted out of _review (kept for a future recovery feature)
unplayable.jsonWhich files the Play button couldn't play (so it stays greyed)
perf.jsonLearned read speed, for the full-hash time estimate
logs/Error logs (only if something went wrong)
_review/ (inside a scanned/root folder)Files you moved, waiting for you to delete or undo

To start completely fresh, close the app and delete those files.

Uninstall

Delete the app folder (including .venv). To also clear saved keys, sign out of Plex in Setup and remove the app's entries from Windows Credential Manager / macOS Keychain (named hackon-dedupe).

Notes on a packaged release

A windowed desktop build (its own window; quits when you close the browser) exists for Windows. A one-click installer — signed Windows .exe / Mac .app, with Python and FFmpeg bundled — is still on the roadmap, so until then the from-source steps above are the way.
